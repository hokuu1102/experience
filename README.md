## 二、更新约定（每次排查完问题后执行）

1. **过程** → `TROUBLESHOOTING.md`：现象 / 假设 / 验证 / **失败尝试** / 根因 / 回归结果，
   编号接排，顶部索引补行。**失败路径本身就是经验**，必须写。
2. **可复用结论** → 按类型分流：
   - 代码逻辑 / 时序 / 设计思路 → 逻辑集 `L##`
   - 工具 / 软件 / 操作流程 → 工具集 `U##`
   - 环境 / 编译报错 → `FPGA问题排查手册.md`
   - 能跨语言、跨领域迁移的 → 共性集 `C##`
3. **状态标签**（统一）：`[假设]` / `[验证中]` / `[已基本确认]` / `[已确认]` / `[已排除]`。
   **只有验证过的才能写进"最终方案"。**
4. **推翻旧结论必须当场改旧记录**（保留"错误 → 修正"痕迹，不删历史）。
5. **条目之间用编号互指**（如"见 L44 / U29 / C11"），不要复制粘贴正文。
6. **生成物不入库**（见 `.gitignore`）：`*.fst / *.vvp / logs/ / __pycache__` 等。

## 四、当前工程主线（截至 2026-09-11）

- 器件：高云 **GW5AT-LV60PG484AC2**（基石板）+ 微相 **ADA107**（3PA1030 ADC / 3PD5651E DAC）
- 教学模块：P0~P16 全过仿真；题1/2/3 已上板；题4/5 有量化墙（5mVpp = 0.51 LSB）
- **坏值根因已结案**（T53：采样相位落在 ADC 数据跳变窗口内 → 135° 修复，板上 A/B 实证）
- **阶段2a-2 已完成**（T56）：`raw_dump` 抽取回传（`S` 命令 + `#DEC` 头）→ 题2"时域 ≥2 周期"
  在 100Hz~2MHz 全段成立；上位机 `live_scope.py` 按 `#DEC` 自适应横轴
- ⚠️ **2026-09-11 起板子不可用 → 只能理论/仿真验证**：固件回归用 `ADDA/sim/run_sims.py`
  （快 ≈140s；`--long` 追加整机端到端 ≈450s），上位机链用 `tools/run_scope.bat --selftest`
- 未闭环：① 低频 Vpp(<50kHz)/频率(<20kHz)/频谱(<20kHz) 三条限制（修复路径见验收口径文档 §8）
  ② 假穿越"迟滞 v2 是否真修好低频"（需一帧 1kHz 原始数据，发 `R`）
  ③ **PLL 越规格运行**（声明 100MHz / 实物 50MHz → VCO≈350MHz < 下限 700MHz）：
     实测正常（80s / 99,894 行 0 异常），**已决策「现阶段不改、只修口径」**；
     有板后首选「只把 VCO 拉回规格、输出仍保持 25MHz」。见 T57 / U34、
     `PLL输入频率声明修正_利弊与计划_2026-09-11.md`
- **2026-09-10 结案**：采集"偶发坏值"根因 = 采样时钟 `clkout1` 相位落在 ADC 数据跳变窗口内
  → 相位 **270°→135°** 后异常样本 3.7%/2.7% → **0**（A/B 实测）
